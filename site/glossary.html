Glossary

HTML
Stands for HyperText Markup Language, the standard language to create websites.
Tags
Enclosed in angle brackets. An example would be 'p', which is the paragraph tag.
Elements
Used to create things in HTML. They contain a starting tag, content, and an end tag. For example, meta elements.
Attributes
Used to provide additional context. For example, `alt` is used to describe what an image is.
CSS
Stands for Cascading Style Sheets, used to style and layout HTML elements.
